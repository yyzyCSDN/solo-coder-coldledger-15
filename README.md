# ColdLedger Pharmaceutical Cold-Chain Operations Lab

Dependency-free Python reference implementation for temperature-sensitive pharmaceutical distribution. It models inventory expiry, chain-of-custody, telemetry correction, packaging qualification, dry-ice depletion, freezer allocation, customs holds, serialization, recalls, release decisions, vehicle compartment compatibility, returns, SLA calendars and cross-dock state. Temperature-excursion disposition chains case state, a frozen evidence graph, conflict-checked independent review panels, tie-broken ballots and final release into a hash-chained audit trail where later decisions supersede but never overwrite earlier ones.

Runtime third-party dependencies: none.
